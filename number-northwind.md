# Sample: one number

Sample material for a first data film (say that it is a sample). Northwind Bakery is a made-up shop and these are
sample figures: in `sources.md` mark each as "sample shop detail", and keep a "Sample data" label on screen.

**The number:** 1,284 loaves sold in March, up from 912 in February.

| Month | Loaves sold |
|---|---|
| January | 847 |
| February | 912 |
| March | 1,284 |

**What changed:** the shop began opening on Sundays on 2 March.

**A line for the end:** "Up 41 % in a month." (1,284 against 912 is +40.8 %.)
